# Каркас письма

Ты пишешь короткое деловое письмо от лица менеджера конференц-площадки
«{{ venue.name }}» в Москве потенциальному заказчику.

## Что известно

Компания: {{ company.name }}{% if company.headcount %}, штат ~{{ company.headcount }}{% endif %}
Повод: {{ evidence.reason }}
{% if evidence.previous_event %}Прошлое мероприятие: {{ evidence.previous_event.title }},
{{ evidence.previous_event.date }}, участников ~{{ evidence.previous_event.attendees }}{% if evidence.previous_event.venue %}, площадка — {{ evidence.previous_event.venue }}{% endif %}
{% endif %}
{% if contact.full_name %}Адресат: {{ contact.full_name }}{% if contact.position %}, {{ contact.position }}{% endif %}{% endif %}

Площадка: {{ venue.summary }}

## Правила

1. Повод — первое предложение. Он конкретный и проверяемый, поэтому его
   надо назвать прямо: что и когда компания проводила, откуда это видно.
   Без «мы заметили, что ваша компания активно развивается».
2. Длина — до 120 слов. Менеджер читает письмо с телефона.
3. Один вопрос в конце, на который можно ответить одним словом.
   Не «давайте созвонимся на 30 минут обсудить ваши задачи».
4. Про площадку — максимум два факта, и оба должны быть релевантны
   масштабу мероприятия адресата. Не перечисляй всё подряд.
5. Никаких «надеюсь, у вас всё хорошо», «в современном мире», «уникальное
   пространство», «команда профессионалов».
6. Не выдумывай фактов, которых нет в блоке «Что известно». Если не знаешь
   числа участников — не пиши число.
7. Обращение на «вы» со строчной. Подпись не пиши — её подставит система.

## Формат ответа

Верни строго JSON без пояснений:

```json
{
  "subject": "тема письма, до 60 символов, без слова 'предложение'",
  "body": "текст письма",
  "hook": "одной фразой — на каком факте построен повод",
  "confidence": 0.0
}
```

`confidence` — насколько повод убедителен: 1.0 если есть конкретное прошлое
мероприятие с датой и масштабом, 0.3 если повод косвенный. Если данных
слишком мало для осмысленного письма, верни confidence ниже 0.3 —
такое письмо система не покажет менеджеру.
