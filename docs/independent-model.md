# Независимая оценка матчей

С версии `independent-history-analysis-v17` новые ИИ-разборы не используют
коэффициенты Winline. Они остаются в каталоге и исходном архиве. В контекст ИИ
передаются только условия рынков: названия, периоды, пороги, исходы и состояния.
Вероятности по линии, маржа и цены удаляются, включая вложенные записи источника.
Нет резервного расчёта из коэффициентов при нехватке истории.

## Выбранная модель

Для предматчевого футбола используется независимая модель голов Пуассона
с эмпирическим байесовским сглаживанием Gamma–Poisson. Она позволяет из одного
распределения счёта получить согласованные П1/Х/П2, двойной шанс, тоталы,
индивидуальные тоталы, обе забьют, точный счёт, победу без ничьей и поддерживаемые
половинные форы. Это первая проверяемая модель, а не утверждение о её превосходстве
над рынком. Qwen выбирает аргументы из подтверждённых фактов; числа считает сервер.
Сезонные агрегаты из виджета используются как факты в аргументации, а не
подменяют полную выборку завершённых матчей для подгонки параметров.

Матчи берутся из того же турнира за последние 365 дней. Архив и виджет
объединяются с удалением дублей. В выборке нужны не менее 30 уникальных матчей
турнира; у каждой команды — не менее пяти прошлых матчей. Используются до
30 последних игр команды. Вес встречи экспоненциально уменьшается с давностью:
период полураспада — 90 дней. Сумма весов каждой команды должна быть не менее трёх.
Коэффициенты букмекера, новости, заметки пользователя и будущие матчи на эти
параметры не влияют. Травмы и текущие составы пока не входят в математическую модель.

Пусть `w_i = 2^(-days_i / 90)`, а `μ` — среднее число голов одной команды
за матч в турнире с этими весами. Сглаженные показатели команды:

```text
attack  = (6 × μ + Σ w_i × goals_for_i)     / (6 + Σ w_i)
defence = (6 × μ + Σ w_i × goals_against_i) / (6 + Σ w_i)
```

Шесть условных матчей с показателем турнира уменьшают влияние маленькой выборки.
По турнирным результатам отдельно оцениваются средние голы хозяев `μ_H` и гостей
`μ_A`, также со сглаживанием к `μ`. Коэффициент позиции хозяев:
`v = sqrt(μ_H / μ_A)`.

```text
λ_home = attack_home × defence_away / μ × v
λ_away = attack_away × defence_home / μ / v
P(H=h, A=a) = Poisson(h; λ_home) × Poisson(a; λ_away)
```

Вероятность П1 — сумма ячеек `h > a`, ничьей — `h = a`, П2 — `h < a`.
Тоталы и другие поддерживаемые условия суммируют соответствующие ячейки той же
матрицы. Для целочисленного тотала вероятность возврата показывается отдельно.
Проценты исхода доступны и без свежей линии букмекера. Наличие свежих доступных
рынков влияет только на то, какие условия можно показать в блоке рынков.

Это модель с независимыми голами; корреляция низких счетов, сила каждого соперника
через отдельный рейтинг, изменения составов, травмы и отдельная поправка на
нейтральное поле пока не моделируются. Поправка хозяев оценена по турнирным данным.
Параметры и формулы не отправляются в публичный ответ и интерфейс.

## Привязка истории виджета

Адаптер понимает время в `time.uts`, `_dt.uts`, `start_at` и `date`, а турнир —
по явному названию либо совпадающему `_utid`/`_tid` с привязанным текущим матчем.
Участник проверяется по идентификатору; `uid` сопоставляется только с `uid`,
а не с `_id` из другого пространства. Записи из `unverified_matches` не используются.

Признак завершения — явный допустимый статус, например `100` или `finished`.
Если статус отсутствует, требуется единственный архивный финальный результат
с теми же участниками, счётом, турниром и временем начала (расхождение до 120 секунд).
При таком подтверждении используется время архивного результата для удаления дублей.
Наличие счёта и прошедшая дата сами по себе не считаются доказательством завершения.
Отменённые, отложенные, технические результаты, неподтверждённые периоды, будущие
матчи и текущая встреча исключаются. Разные турниры не смешиваются ради размера выборки.

В `probability_assessment.history_diagnostics` и журнале `Independent model`
сохраняются размеры выборок и причины исключений. Отсутствие подходящей истории
даёт сводку без процентов, даже когда виджет содержит много других записей.
Live и другие виды спорта пока также получают фактическую сводку без процентов.

## Обновление и проверка

При нажатии ИИ-разбора выбранная потоковая встреча сразу ставится в очередь
обновления дополнительных рынков. Пока её задание статистики активно, наблюдение
не истекает через прежние две минуты. Обновление рынков и получение статистики
работают параллельно через существующие сборщики; другие встречи не обходятся.
После статистики браузер ждёт дополнительные рынки до десяти секунд. Отсутствие
подтверждённого обновления не отменяет независимую оценку по истории.

Регрессионные проверки меняют коэффициенты на крайние значения и полностью
удаляют их: вероятности, математические факты и выбранные рынки должны оставаться
теми же. Проверяется отсутствие цен в реальном запросе к Qwen, отсутствие
подстановки вероятностей по линии и отбрасывание неподтверждённых результатов.

Для проверки точности нужно накапливать прогнозы до начала встреч и сопоставлять
с последующими результатами: `python -m matchlab.chances_audit` считает Brier score,
log loss и калибровку фаворита. Синтетические тесты не доказывают качество прогнозов.
Пока нет достаточной проверки на будущих матчах, отчёт сохраняет это ограничение.
