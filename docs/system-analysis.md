# Системная подборка на сегодня и завтра

Одна настройка в админке включает оба этапа: сначала свежие главные события
Winline, затем предстоящие матчи из каталога до пяти доступных рекомендаций
«Ставить» в подборке на сегодня и завтра по МСК. Главные события проверяются
даже при заполненной подборке; пять — цель дополнительного поиска, не лимит
публикации уже полученных главных прогнозов.

Дополнительная очередь чередует доступные виды спорта; внутри каждого вида
сначала берётся ближайшее время начала. Позиция чередования и обработанные
события сохраняются в БД, поэтому перезапуск не повторяет системные решения.
Настольный теннис, неподдерживаемые форматы, лайв, начавшиеся, устаревшие,
отсутствующие в источнике события и даты после завтра исключены.

Счётчик использует тот же набор, что опубликован в «Выборе ИИ»: только готовые
системные рекомендации «Ставить», по одному событию. Пользовательские ответы,
претенденты при «Пропустить», ошибки и отсутствие данных цель не заполняют.
Рекомендации не подгоняются под цель: если каталог исчерпан, сервис ждёт новых
матчей. После начала матча карточка перестаёт занимать место и поиск возобновляется.

Сохраняется один последовательный системный поток и один пользовательский.
В админке видны прогресс к пяти карточкам и источник каждого задания — главные
события или предстоящие матчи. Выключение настройки приостанавливает новые
задания; уже запущенный ответ сохраняется. Пользовательские лимиты и баланс
системные запросы не расходуют.

Установка: обновить main и перезапустить только `matchlab.service` на VPS сайта.
Колонка `selection_source` добавляется автоматически с сохранением старых строк.
