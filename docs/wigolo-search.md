# Интернет-поиск для ИИ-разбора

Matchlab на VPS сам обращается к инструменту `search` по MCP. Wigolo 0.3.1
работает отдельной службой на сервере нейросети; обратный SSH-туннель связывает
два локальных порта. Модель Qwen получает ограниченную подборку выдержек с
номерами, ссылками и датами. Пользователь видит ссылки вместе с разбором.
Никакие команды, инструменты Wigolo кроме `search` или произвольные URL от
модели не выполняются. В поиск передаются названия участников, спорта и турнира,
но не заметки пользователя или данные аккаунта.

Wigolo — отдельный сторонний проект в публичной бета-версии, распространяемый
по AGPL-3.0: https://github.com/KnockOutEZ/wigolo. Использование поиска без
ключа не означает приватность запросов от внешних поисковых систем. Поисковики
могут ограничивать доступ, результаты могут быть нерелевантны, без даты или
неполны. Сервис не проверяет факты автоматически и не гарантирует улучшение
прогнозов. Модели и браузер Wigolo могут скачиваться по мере работы; следите за
свободным местом. Установщик ниже использует официальный бинарный релиз x86_64,
проверенный по зафиксированному SHA-256; отдельный Node.js не нужен.

Приложение отбрасывает явно посторонние результаты, которые не содержат имени
одного из участников. Для команд с пометкой «люб.» дополнительно требуется
упоминание любительского статуса или турнира. Это не проверка достоверности и
может скрыть подходящий материал, если в выдаче имя написано иначе. Участников
с одноимёнными профессиональными клубами автоматически объединять нельзя.

Внутри одного разбора выполняются до трёх поисковых запросов, выбираются не
более восьми источников и до 1200 символов выдержки на источник. Используется
быстрый поиск по выдаче без дополнительной загрузки страниц, чтобы уменьшить
тайм-ауты. Это подборка, а не весь интернет или полные тексты статей. Дату публикации не следует
путать со временем поиска, а старые разборы не обновляются задним числом.
Результаты одного запроса кэшируются приложением на 5 минут; Wigolo получает
команду обновлять свои поисковые данные. При частичном или полном отказе
поиска разбор использует другие доступные сведения.

Если в запросе нет подтверждённой статистики, истории или модели, формируется
автоматическая сводка по сохранённому счёту и рынку. Одни поисковые ссылки не
заменяют проверенные результаты участников:
Qwen не вызывается, а забронированный промобонус возвращается. Это помогает
избежать необоснованных выводов при нехватке данных.
Для полного открытого рынка 1X2 сводка также показывает доли, полученные
пропорциональной нормировкой обратных коэффициентов, и сумму этих коэффициентов
до нормировки. Расчёт относится только к названному рынку и периоду; это не
независимый прогноз и не доказанная вероятность события. Если исходы закрыты,
обрезаны или неоднозначны, такой расчёт не выполняется.

## 1. Сервер нейросети

Нужны Linux x86_64, установленный работающий управляемый туннель
`matchlab-scraper-tunnel.service`, `curl`, `python3`, `sha256sum` и минимум
2 ГиБ свободного места в `/var/lib`. Сам бинарный файл занимает около 200 МБ;
первое использование может дополнительно загрузить браузер и модели. Служба
ограничена 1 ГиБ оперативной памяти и половиной одного CPU; GPU для поиска не
настраивается. Установщик не меняет модель, сборщик архива и их окружения.

```bash
cd ~/matchlab-scraper-src
git pull --ff-only origin main
sudo bash scripts/install_wigolo.sh
sudo python3 scripts/install_wigolo_tunnel.py
sudo systemctl status matchlab-wigolo matchlab-wigolo-tunnel --no-pager
```

Первый скрипт создаёт собственную учётную запись, каталог данных, ключ и
службу `matchlab-wigolo`. Она слушает только `127.0.0.1:13334`, и к её MCP
требуется токен. Второй скрипт создаёт **отдельную** службу SSH, используя
пользователя, проверку ключа хоста и SSH-идентификатор уже существующего
управляемого туннеля сборщика. Через SSH он передаёт токен на VPS в
`/etc/matchlab-wigolo-token` с правами `600`, не печатая его, и открывает на
VPS только `127.0.0.1:13333`. Существующий туннель не перезапускается.

Второй скрипт намеренно останавливается при нестандартной SSH-конфигурации,
дополнительных systemd-настройках, отсутствии root-доступа к VPS или если на
VPS уже находится другой токен. В таком случае не присылайте токен: изучите
ошибку и настройки `sudo systemctl cat matchlab-scraper-tunnel`. Если порт на
VPS уже занят, отдельный туннель не запустится; смотрите его журнал.

## 2. VPS сайта

Команды ниже предполагают существующую установку `/root/matchlab` и службу
`matchlab.service` от root. Они не меняют Nginx или сертификат.

```bash
cd /root/matchlab
git pull --ff-only origin main
.venv/bin/python -m pip install -r requirements.txt
sudo nano /root/matchlab/.env
```

В редакторе добавьте две строки (если они уже есть, измените существующие):

```dotenv
WIGOLO_MCP_URL=http://127.0.0.1:13333/mcp
WIGOLO_MCP_TOKEN_FILE=/etc/matchlab-wigolo-token
```

Сохраните файл. Ключ в `.env` и в чат копировать не требуется. Проверьте
MCP и настоящий поиск на примере команды, затем перезапустите приложение:

```bash
cd /root/matchlab
curl -fsS http://127.0.0.1:13333/health
.venv/bin/python -m matchlab.web_research --home Арсенал --away Челси --sport Футбол --competition АПЛ
sudo systemctl restart matchlab.service
sudo systemctl status matchlab.service --no-pager
```

Пробный поиск отправит указанные названия в поисковые системы. `state: ready`
и непустой список `sources` означают, что MCP вернул данные; проверяйте
релевантность и даты вручную. `empty` означает, что подходящая выдача не найдена;
`unavailable` — нет доступа к MCP, токену или поиск завершился ошибкой.

При `unavailable` поле `error_code` содержит безопасную категорию ошибки:
`token_missing`, `token_unreadable`, `authentication_failed`, `connection_failed`,
`timeout` или `provider_or_configuration_error`. Значения ключей и текст ошибок
провайдера не выводятся. Лог приложения на VPS также содержит категорию ошибки.

Посмотрите журналы на сервере нейросети:

```bash
sudo journalctl -u matchlab-wigolo -n 40 --no-pager
sudo journalctl -u matchlab-wigolo-tunnel -n 40 --no-pager
```

Эти два журнала находятся на сервере нейросети. `/health` показывает только
живость сервиса и не проверяет поиск, авторизацию MCP или качество результатов.
Если на VPS используется непривилегированный пользователь приложения,
обеспечьте ему безопасный доступ к копии токена без предоставления доступа
другим пользователям; не делайте файл общедоступным.

После обновления откройте матч и запросите новый ИИ-разбор. При наличии
поисковой выдачи блок «Интернет-источники» покажет ссылки. Список содержит
отобранные материалы, даже если модель использовала не каждый из них.
Старые сохранённые разборы останутся без новых источников. Чтобы отключить
поиск, удалите обе переменные из `.env` и перезапустите `matchlab.service`.
