# Замер параллельных ответов Миры на 128К

На GPU-сервере используется системная служба `englishbot-huihui.service`, а генератор фото установлен как пользовательская служба `mira-photo.service`. Переключение Strata кратковременно прерывает активные ответы всех клиентов этого движка.

## Подготовка

На VPS сайта обновите ветку и перезапустите сайт.

```bash
cd /root/matchlab &&
git pull --ff-only origin feat/companion-chat &&
systemctl restart matchlab.service
```

На GPU-сервере войдите как пользователь, под которым работал генератор. Скрипт удаляет его службу, основные файлы запуска и отдельную Python-среду. В профиле Strata прежний резерв для фото 9216 или 16384 МиБ заменяется на 2048 МиБ для CUDA. Скрипт определяет профиль по аргументу `--profile` или `--config` работающей службы и печатает путь к резервной копии при изменении. При остановленной службе путь можно указать явно через `--profile`. Общие кэши весов, ранее созданные изображения и службы распознавания и синтеза речи сохраняются.

```bash
cd ~ &&
scp root@89.111.143.45:/root/matchlab/scripts/strata_gpu.py ./strata_gpu.py &&
python3 ./strata_gpu.py --retire-photos --context 131072 --slots 1 &&
sudo systemctl restart englishbot-huihui.service
```

Проверьте фактические аргументы дочернего процесса после загрузки. Активное состояние оболочки systemd само по себе не подтверждает готовность отвечать. Для обычного движка скрипт записывает число слотов в поле `parallel` профиля. Если служба передаёт свой `--parallel`, именно он определяет число слотов. При одном слоте Strata может опустить флаг batch.

```bash
parent=$(systemctl show englishbot-huihui.service -p MainPID --value)
for pid in $(pgrep -P "$parent"); do
  tr '\0' '\n' < "/proc/$pid/cmdline" |
    awk '/^--(max-context|batch|vram-reserve-later-mib|resident-budget-gib)$/ {opt=$0; if (getline) print opt,$0}'
done
nvidia-smi --query-gpu=index,memory.free,utilization.gpu --format=csv
```

## Сравнение

После загрузки на VPS сайта измерьте один поток. Первый короткий вызов прогревает модель. В измерениях используются независимые синтетические запросы через адрес Qwen из настроек сайта. Команда не входит в аккаунты пользователей.

```bash
cd /root/matchlab &&
.venv/bin/python -m matchlab.companion_bench --parallel 1 --rounds 3
```

Для теста занятого окна используйте на VPS сайта следующий блок в период низкой нагрузки. Скрипт оценивает длину по двум коротким запросам и выводит фактический диапазон токенов, сообщённый движком. Большой холодный запрос может надолго занять слот. Метрики относятся к указанной длине входа.

```bash
cd /root/matchlab &&
.venv/bin/python -m matchlab.companion_bench --parallel 1 --rounds 1 --input-tokens 120000 --timeout 7200
```

Для сравнения со вторым слотом на GPU-сервере выполните:

```bash
python3 ~/strata_gpu.py --context 131072 --slots 2 &&
sudo systemctl restart englishbot-huihui.service
```

Повторите оба замера на VPS сайта с `--parallel 2`. Сравните медиану времени до первого видимого текста и медиану полного ответа с предыдущим профилем при одинаковой длине входа. Суммарная скорость описывает сервер целиком, включая время ожидания и обработку промпта. Для оценки разброса повторите длинный замер в нескольких раундах. При необходимости аналогично проверьте четыре слота. Одновременные соединения сверх числа активных слотов могут ожидать в очереди.

При нехватке памяти на запуске или первом реальном запросе верните предыдущий профиль. В переменную укажите точный путь к копии, напечатанный перед соответствующим переключением.

```bash
read -r -p 'Полный путь к резервной копии профиля: ' strata_backup
read -r -p 'Полный путь к активному JSON-профилю службы: ' config_path
test -f "$strata_backup" && test -f "$config_path" &&
python3 -m json.tool "$strata_backup" >/dev/null &&
cp -- "$strata_backup" "$config_path" &&
sudo systemctl restart englishbot-huihui.service
```

В профиле Миры настройка «Учитывать в ответах до 40 пар сообщений» расширяет передаваемую текстовую историю с 8 до 40 пар. После проверки окна движка выставьте `QWEN_CONTEXT_TOKENS=131072` в активном окружении службы сайта (при обычной установке в `/root/matchlab/.env`) и перезапустите `matchlab.service`. До этого приложение при незаданном лимите рассчитывает объём истории на 32768. Длинная последовательность сокращается по целым парам с запасом под ответ.
