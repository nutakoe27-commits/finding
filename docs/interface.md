# Пользовательский интерфейс

Основной путь: **найти матч → открыть ИИ-разбор → прочитать решение и аргументы → вернуться к нему в личной истории**.

## Поиск и каталог

Поиск находится перед каруселью и применяется на сервере до пагинации. Вид спорта,
статус, турнир и дата задают область поиска. Выбранные условия показаны отдельными
кнопками: можно убрать одно ограничение, сохранив введённое название команды.
Escape очищает строку поиска. Неудавшуюся загрузку можно повторить без перезагрузки
страницы.

Карусель повторяет состав и порядок наблюдённого блока главной страницы Winline.
Она не пересортировывается по фильтрам каталога, не перелистывается автоматически
и поддерживает свайп и клавиатуру. Для Live и других видов спорта в текущем режиме
neural-verdict основное действие открывает матч, не создавая заведомо неподдерживаемый
запрос к ИИ.

Возврат из матча восстанавливает фильтры, страницу списка и положение прокрутки.
Состояние раздельное для каталога и избранного, хранится в памяти открытой вкладки.
Избранное сохраняется в этом браузере; новый раздел избранного показывает все
сохранённые события без ограничения одним видом спорта или только предматчем.
Фокус кнопок и ссылок сохраняется при автоматическом обновлении списка.

## Страница матча и ИИ

Пользователь видит встречу, время и наблюдаемые коэффициенты, затем блок разбора,
далее — все доступные рынки. В neural-verdict коэффициенты доступны для просмотра;
вердикт относится к победе команды в основное время. Числовой расчёт, диагностика,
архив результатов и история участников остаются в интерфейсе администратора.
Скрытие технических панелей не меняет серверный сбор фактов для ИИ.

Индикатор ожидания показывает этап подготовки и фактическое время ожидания, без
выдуманного процента готовности. Пока сведения собираются, предлагается остаться
на странице. После подтверждения задания сервером появляется сообщение о фоновом
выполнении и сохранении ответа в истории. При отсутствии оснований остаётся явное
решение «Претендент: Никто / Пропустить матч».

На широком экране готовый ответ расположен рядом с блоком запроса; на телефоне —
под ним. Текст можно скопировать явным нажатием кнопки. Новый формат интерфейса не
меняет проверки фактов, повторные попытки модели, лимиты и правила списания.

## Личная история и аккаунт

Гость видит объяснение назначения личной истории и кнопку входа. Существующие
разборы не показываются. Пользователь может искать по полученным личным разборам,
открывать сохранённый ответ и копировать его. Поиск действует в пределах последних
разборов, возвращённых личным API, и не выдаётся за поиск по всей базе.

Вход и регистрация сохраняют прежние подтверждения документов и возраста. Пароль
можно показать, скрыть и снова скрыть при переключении формы. На телефоне основные
разделы находятся в нижнем меню с учётом безопасной области экрана. Светлая и тёмная
темы используют одинаковые компоненты; системное уменьшение анимации учитывается.

## Обновление

Изменяется только сайт на VPS. Сборщики, модель, её параметры и SSH-туннели не
требуют перезапуска:

```bash
cd /root/matchlab &&
git pull --ff-only origin main &&
sudo systemctl restart matchlab.service
```

Новых Python-пакетов и миграций базы нет.

## Целевые проверки интерфейса

```bash
PYTHONPATH=tests .venv/bin/python tests/browser_product_ux.py
PYTHONPATH=tests .venv/bin/python tests/browser_featured_recovery.py
```

Первая проверка покрывает поиск, фильтры, возврат и пагинацию, фокус, повтор загрузки,
вход, этапы ожидания, личную историю, копирование и разделение ролей в Chromium
на ширинах 1440, 1024, 390 и 320 пикселей. Вторая проверяет сохранённый сценарий
ИИ-разбора с локальным HTTP-заменителем модели. Реальная модель не вызывается.
