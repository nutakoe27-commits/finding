# Оплаты в административной панели

Раздел **Управление → Оплаты** доступен только администратору. API проверяет роль
при каждом запросе, ответы не кэшируются. При выходе из аккаунта отчёт и карточка
заказа очищаются. Просмотр не обращается в ЮKassa и не меняет платежи/балансы.

Фильтры: период создания заказа (включая всё время), тестовый/реальный режим, статус, поиск по
логину, ID заказа/платежа/пользователя. Есть постраничная таблица и JSON текущей
страницы вместе с показателями и условиями выборки.

Показатели: сумма подтверждённых оплат, возвраты выбранных заказов, сумма после
возвратов, средний чек до возвратов, покупатели, количество заказов/ожидающих/
отменённых/ошибочных, доля оплаченных заказов и начисленные за них единицы.
Сумма после возвратов **не равна прибыли**: комиссии и расходы здесь не учтены.
Полностью возвращённый заказ всё ещё считается когда-то оплаченным; сумма
возврата учитывается отдельно, без повторного вычитания из исходной оплаты.

График показывает заказы по дате создания в МСК, с выделением оплаченных.
Таблица пакетов отражает сохранённые параметры заказа, а не подменяет их
текущими тарифами. Фильтр статуса применяется и к показателям: это сводка
выбранных заказов, а не неподвижный общий оборот магазина.

В карточке заказа: покупатель, пакет, сумма, статус, возвраты, время создания
и обновления записи, ID платежа, редакция принятых условий, ошибка и ID разбора;
также баланс аккаунта, бонусы, число открытых ответов и журнал начислений,
открытий и возвратов с пагинацией. Журнал относится ко всему аккаунту в данном
режиме: текущая тестовая модель не связывает каждую потраченную единицу с
конкретным купленным пакетом, и интерфейс не выдумывает такую связь.

Историческое время фактической оплаты отдельно не записывалось. `updated_at`
может измениться при проверке или возврате, поэтому оно подписано как время
обновления записи. Секретные ключи, платёжные ссылки, пароли, токены сессий и
личные заметки в отчёт не передаются.

По умолчанию открыт **тестовый магазин** с заметным предупреждением, что
реальные деньги не списывались. Реальный режим пока пуст; его наличие в
фильтре не включает приём денег. Редактирования заказов, возвратов и ручного
начисления из этого раздела нет.
