# BetBoom и Winline: захват образца для диагностики

Облачная среда разработки сейчас не имеет сетевого доступа к сайтам букмекеров.
Инструмента управления личным компьютером пользователя в этой сессии нет.
Сохранённый пользователем образец от 08.11.2026 уже использован для подключения
предматчевого футбольного 1X2. Рабочий сбор, импорт и интерфейс описаны в
[bookmaker-line.md](bookmaker-line.md). Этот инструмент остаётся средством
получения воспроизводимого образца при изменении сайтов, а не утверждением
полноты букмекерского каталога.

Для macOS нужен Python 3.10 или новее. Если установлен Homebrew, Python 3.12
можно установить командой `brew install python@3.12`.

## Запуск на Mac

Откройте новое окно Терминала **на Mac, вне SSH-сессии VPS**:

```bash
git clone --branch main --single-branch \
  https://github.com/nutakoe27-commits/finding.git ~/matchlab-collector
cd ~/matchlab-collector

python3.12 -m venv .collector-venv
.collector-venv/bin/python -m pip install -r requirements-capture.txt
.collector-venv/bin/python -m playwright install chromium

.collector-venv/bin/python scripts/capture_bookmakers.py \
  --source both --seconds 180 \
  --output "$HOME/Desktop/bookmakers-capture-$(date +%Y%m%d-%H%M%S).json"
```

Если подходящий Python запускается как `python3`, используйте его вместо
`python3.12` при создании окружения. Если репозиторий уже скачан, обновите его
через `git pull --ff-only origin main` вместо повторного клонирования.

Сборщик откроет BetBoom и Winline в двух вкладках нового профиля Chromium.
В каждой вкладке выберите **футбол → линия до матча → Англия, Премьер-лига**,
прокрутите список и откройте карточку одного матча. При отсутствии АПЛ можно
собрать другую футбольную лигу для изучения структуры; текущая прогнозная модель
сервиса при этом остаётся моделью АПЛ.

Действуйте только на публичных страницах, без входа в букмекерский аккаунт.
Разрешённые сайтом ручные подтверждения в открытом браузере выполняет сам
пользователь. Сборщик не решает CAPTCHA, не авторизуется и не нажимает
коэффициенты или кнопки размещения ставок. Дождитесь автоматического закрытия
отдельного браузера и сохранения файла через три минуты после загрузки страниц.

Файл с именем `bookmakers-capture-....json` появится на Рабочем столе. Его можно
передать разработчику для проверки адаптеров. Это не HAR: HTTP-заголовки,
запросы авторизации, тела запросов, cookies и значения полей форм не сохраняются.
Браузер не использует обычный профиль Chrome/Safari пользователя.

## Что находится в файле

- источник: `betboom` / `winline`;
- время наблюдения в UTC и адрес без значений query-параметров;
- публичные JSON-ответы и JSON-сообщения WebSocket, похожие на спортивные данные;
- видимый текст футбольной линии и ограниченный набор DOM-атрибутов;
- список транспортных endpoint'ов, HTTP-статусы, статистика и ограничения;
- SHA-256 очищенного payload для повторного разбора.

Из известных чувствительных JSON-полей удаляются значения. Это дополнительная
мера, а не гарантия обезличивания любых произвольных данных: соблюдайте область
сбора и не входите в аккаунт во время записи. Часть публичных конфигурационных
JSON сохраняется для изучения схемы и не считается спортивными данными.

Бинарные WebSocket-кадры только подсчитываются. Их нельзя назвать разобранными
матчами без установленной схемы протокола. Для таких сайтов сохраняется видимый
DOM, в том числе содержимое публичных iframe. Поддержка нормализации по
конкретному формату проверяется отдельно на реальном образце.

Лимиты: 8 MiB на payload, 12 MiB на суммарные payload, до 100 сетевых payload
и до 24 изменившихся DOM-снимков на источник. Метаданные явно показывают
усечение и достижение лимитов. Повторные одинаковые JSON объединяются с
счётчиком и временем последнего наблюдения. Существующий файл не перезаписывается.

Если хотя бы один источник не дал распознаваемых спортивных данных, программа
сохраняет диагностический файл и завершается кодом 2. Нулевой сбор не выдаётся
за работоспособный скрапер.

## Дополнительные команды

```bash
# Один источник, больше времени для ручного открытия лиги
.collector-venv/bin/python scripts/capture_bookmakers.py \
  --source betboom --seconds 300

# Показать только сводку уже сохранённого файла
.collector-venv/bin/python scripts/capture_bookmakers.py \
  --inspect /path/to/bookmakers-capture.json

# Браузер без окна, если источник действительно доступен на сервере
.collector-venv/bin/python scripts/capture_bookmakers.py \
  --source winline --headless --seconds 60
```

Сборщик не обращается к Matchlab, не меняет его SQLite-базу, Nginx, systemd,
Docker или существующий SSH-туннель Qwen. На VPS до проверки реальных данных
его устанавливать не требуется.

## Проверка реализации

```bash
.venv/bin/python -m unittest discover -v
# Нужны Playwright и Chromium; тест использует синтетический локальный сайт:
python3 tests/browser_capture_smoke.py
```

Проверены JSON и DOM двух вкладок, timestamps, фильтрация account endpoints,
отсутствие заголовков и значений формы в файле, очистка известных секретных полей,
ограничение объёма и запрет перезаписи. Эти проверки не подтверждают текущую
доступность настоящих сайтов. Адаптеры дополнительно проверены на минимальной
публичной проекции реального захвата пользователя; исходный полный файл
в репозиторий не добавляется.
