# Яндекс Метрика для prognozich ai

Счётчик: **114139580**. Код загружается только после отдельного выбора
аналитики. Вебвизор включается отдельным необязательным флажком; по умолчанию
он выключен. При изменении режима Вебвизора или отзыве согласия страница
перезагружается, чтобы остановить работающий экземпляр счётчика. Старое
согласие на собственную аналитику не считается согласием на Яндекс Метрику.
На отдельных страницах документов счётчик также запускается только при уже
выданном согласии на аналитику; Вебвизор для них отключён.

Код отмечает вводимые поля `ym-disable-keys`, а всё содержимое страницы —
`ym-hide-content`; для Вебвизора раскрывается только публичный список матчей.
Сверяйте настройки и результаты в кабинете Яндекса: в настройках Вебвизора не
включайте «Записывать все поля». Пользовательские заметки, формы, история,
личный кабинет и админ-панель не предназначены для записи.

Счётчик использует `clickmap`, `accurateTrackBounce` и `dataLayer` для будущей
электронной коммерции. Автоматическая отправка исходящих ссылок `trackLinks`
отключена: переход на Winline фиксируется отдельной целью без передачи адреса
партнёрской ссылки. В `reachGoal` не передаются логины, пароли, заметки,
коды промокодов, названия команд и идентификаторы событий. В явных вызовах
просмотры SPA задаются как обобщённые адреса разделов без ID и строки запроса;
referrer ограничен источником (origin). Внешний скрипт Яндекса работает в
контексте страницы и может обрабатывать стандартные сведения браузера и её
фактический адрес; не помещайте персональные данные в URL и проверьте политику
Яндекса и реальные сетевые запросы перед запуском.
Сейчас `dataLayer` не заполняется покупками. При будущей интеграции оплаты не
добавляйте в него реквизиты карты, контактные данные или другие лишние сведения.

## Создание целей в кабинете

Отправка событий реализована в приложении. Доступа к кабинету счётчика у
разработчика нет: события сами по себе не создают цели в интерфейсе Яндекса.
Откройте счётчик 114139580 → настройки → **Цели** → **Добавить цель** →
тип **JavaScript-событие**. Создайте цели с идентификаторами в таблице;
название можно выбрать на русском. Вводите именно идентификатор события,
без скобок, кавычек и дополнительных параметров.

Вместо ручного создания владелец может использовать официальный API Яндекс
Метрики через `python3 scripts/configure_metrika_goals.py`. Скрипт спрашивает
OAuth-токен скрытым вводом в локальном терминале и сначала только показывает
план. Для создания отсутствующих целей запустите его с флагом `--apply`;
существующие цели он не меняет и не удаляет. Не запускайте параллельные копии.
После частичной ошибки повторный запуск сначала заново проверит список целей.
Если имя уже занято другой целью или найдена неактивная цель с тем же событием,
скрипт её пропустит для ручной проверки.

Понадобится OAuth-токен владельца или пользователя с правом изменения этого
счётчика и доступом `metrika:write`; для просмотра также нужен `metrika:read`.
Инструкция Яндекса по получению токена:
https://yandex.ru/dev/metrika/ru/intro/authorization. Токен вводится только в
терминале владельца; не отправляйте его в чат и не кладите в репозиторий.

| Идентификатор | Когда отправляется |
|---|---|
| `registration_success` | Сервер успешно создал аккаунт. |
| `login_success` | Пользователь успешно вошёл. |
| `match_view` | Открыт экран матча или live-события. |
| `ai_intent` | Нажата кнопка «Разбор ИИ» или «Получить разбор ИИ». |
| `ai_request_start` | Начата отправка запроса на разбор; она может завершиться ошибкой. |
| `ai_model_result` | Пользователю показан результат модели, включая ответ из кэша. |
| `ai_summary_result` | Показана автоматическая сводка без вызова модели. |
| `ai_request_error` | Актуальный запрос завершился ошибкой в интерфейсе. |
| `favorite_add` | Матч добавлен в избранное, включая сохранение только на время сессии при недоступном хранилище. |
| `winline_click` | Нажата ссылка перехода на Winline; это не подтверждение открытия или партнёрской конверсии. |
| `promo_redeemed` | Сервер подтвердил активацию промокода. |
| `push_subscribed` | Сервер подтвердил подписку на push; это не подтверждение доставки. |

Оплата и продажа токенов пока не реализованы, поэтому цели покупки и выручка не
передаются. При подключении ЮKassa их нужно привязать к подтверждённому платежу,
а не к нажатию кнопки или возврату на сайт.

## Проверка после развёртывания

1. Без согласия убедиться в DevTools → Network, что запросов к `mc.yandex.ru`
   нет; затем разрешить аналитику и проверить загрузку счётчика и событие.
2. Повторить с отдельным разрешением Вебвизора и проверить маскирование
   пользовательского ввода и личных разделов в кабинете Яндекса.
3. Создать цели выше и проверить тестовые достижения в кабинете. Отозвать согласие
   и убедиться, что после обновления страницы новых запросов нет.
4. Текущие `frame-ancestors 'none'` и `X-Frame-Options: DENY` защищают сайт от
   встраивания. Некоторые интерактивные карты Яндекса, открывающие сайт внутри
   iframe, могут быть недоступны; не снимайте эти ограничения для админки и
   пользовательских данных без отдельного безопасного решения и проверки.

cookie. Проверьте соглашение с Яндексом, роли обработки данных и актуальность
