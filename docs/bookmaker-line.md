# Футбольная линия BetBoom и Winline

Рабочий формат: видимые предматчевые карточки, турнир, команды, начало и
П1/Х/П2 за **основное время**. Декодирование бинарного WebSocket, полный
каталог, live, тоталы, форы и все 1500+ рынков одного матча не заявляются.

На пользовательском захвате от 08.11.2026 распознаны **15 событий BetBoom и
7 событий Winline, 194 наблюдения коэффициентов**. Между источниками есть
пересечения: это 22 карточки букмекеров, а не 22 разные встречи. Повторные
наблюдения не означают 194 изменения цены.

Публичный образец хранится минимальной проекцией в `tests/fixtures/`; весь
исходный файл со служебным трафиком в Git не добавляется. Облачная среда не
имеет проверенного доступа к сайтам, а запись на Mac уже подтвердила получение
публичной линии. Для постоянного обновления нужен работающий браузер на
компьютере, где сайты доступны.

## Обновление VPS

Для постоянного сбора без Mac используйте [серверный сборщик](server-scraper.md).
Он работает на сервере Qwen и передаёт снимки на VPS каждые 60 секунд.

В SSH-сессии сервера:

```bash
cd ~/matchlab
git pull --ff-only origin main
systemctl restart matchlab
```

Новых серверных зависимостей нет. Миграция SQLite добавляет отдельные таблицы,
сохраняя результаты матчей и прогнозы. Историческая выборка и её revision
не меняются при поступлении букмекерских котировок. Nginx, Docker, vLLM и
посторонние сервисы не перенастраиваются.

## Импорт уже полученного файла

В новом Терминале **на Mac, вне SSH-сессии**, передайте исходный файл через
стандартный ввод команды импорта. Подставьте адрес своего VPS:

```bash
ssh root@SERVER_IP \
  'cd /root/matchlab && .venv/bin/python -m matchlab import-bookmakers --stdin' \
  < "$HOME/Desktop/bookmakers-capture-20261108-121029.json"
```

Либо загрузите файл в игнорируемую `.local/` и выполните на VPS:

```bash
.venv/bin/python -m matchlab import-bookmakers .local/bookmakers-capture.json
```

При повторном импорте тех же наблюдений возвращается `inserted: 0`. Неверный
или пустой файл не очищает ранее полученную линию. Разбор и вставка выполняются
до/внутри одной транзакции; частично записанного ошибочного набора не остаётся.
Нормализованный формат также принимается этой командой.

В интерфейсе появится раздел «Матчи букмекеров». Источник можно отфильтровать,
а начавшиеся встречи — посмотреть через отдельный переключатель. Список
обновляется из базы каждые 30 секунд и по кнопке. Это не запускает браузер
на VPS и не делает новых запросов к букмекерам.

Кнопка «Рассчитать» доступна для распознанных команд АПЛ с достаточной историей.
Снимок старше пяти минут явно отмечен: его цена может быть уже недоступна.
Модель обучается на результатах строго до дня наблюдения котировки. Начавшиеся
матчи предматчевым endpoint'ом отклоняются. Пара другого чемпионата не
подставляется в модель АПЛ. Отчёт исторической доходности при этом не появляется.

## Регулярный сбор на Mac

Используется отдельный профиль браузера, без обычных cookies Chrome/Safari.
Нужен Python 3.10+; пример ниже использует окружение из инструкции захвата:

```bash
cd ~/matchlab-collector
git pull --ff-only origin main
.collector-venv/bin/python -m pip install -r requirements-capture.txt

.collector-venv/bin/python scripts/scrape_bookmakers.py \
  --seconds 3600 --interval 30 \
  --output "$HOME/Desktop/bookmakers-live-$(date +%Y%m%d-%H%M%S).json" \
  --ssh-target root@SERVER_IP
```

Для автоматической передачи нужен доступ по **SSH-ключу** и заранее проверенный
host key сервера. Используйте свой SSH alias, если порт или ключ задаются через
`~/.ssh/config`. `BatchMode=yes` предотвращает повторные запросы пароля.
Настройки SSH и проверка host key не отключаются. После первой неудачной
передачи новые попытки прекращаются до перезапуска сборщика: локальная запись
продолжается, завершение отмечается кодом 2. Исправьте SSH-доступ перед повтором.

`--remote-dir` по умолчанию `/root/matchlab`; при другом размещении укажите
фактический абсолютный путь. Передаётся только нормализованный публичный набор
через stdin. На VPS выполняется команда импорта, а не перезапуск служб.

На Mac сохраняются последний JSON и соседний файл `*.history.jsonl` со всеми
успешными пакетами наблюдений. Новый запуск требует новое имя, чтобы не затереть
прошлую запись. Без `--ssh-target` работает только локальное сохранение; тогда
последний JSON можно импортировать отдельно.

Держите вкладки на списках предматчевой линии. BetBoom открывается на наблюдавшейся
странице АПЛ `/sport/football/128/216`, Winline — на главной. При необходимости
вручную выберите в Winline футбол и АПЛ. Браузер ничего не нажимает, не входит
в аккаунт и не размещает ставки. Требуемые сайтом ручные подтверждения выполняет
пользователь. Если страница не загрузилась, не распознана или изменила формат,
нулевой результат не выдаётся за успешный сбор; прежние серверные данные стареют
с видимой отметкой, а не подменяются пустой линией.

Сессия длится час; остановка — Ctrl+C. Последние записанные пакеты сохраняются.
Буферы и бюджеты захвата сбрасываются каждые 30 секунд, браузерная сессия остаётся
той же, поэтому лимит первоначального захвата не останавливает дальнейшие пакеты.

## Ограничения подтверждённого формата

- BetBoom: список футбольного турнира, футбольные карточки главной и точная
  секция «Исход → Основное время» на странице матча. Досрочная победа и таймы
  исключены. Формы команд вроде `6-1-2` не считаются коэффициентами.
- Winline: предматчевые карточки с публичными ссылками события. На смешанной
  главной спорт и турнир подтверждаются совпадением **обеих команд и времени**
  с явно футбольной карточкой BetBoom. Три числа сами по себе не доказывают,
  что это футбол: хоккей и прочие неподтверждённые карточки пропускаются.
- Отображаемое время разобрано как Europe/Moscow, что соответствует захвату
  и принудительному timezone отдельного браузера. В базе хранится UTC.
- Названия команд сопоставляются по явным alias, без нечёткого угадывания.
- Каждый снимок хранит источник, время, parser version и отдельную тройку
  коэффициентов. «Лучшие» цены разных букмекеров в один рынок не смешиваются.
- Запись не гарантирует получение каждого промежуточного изменения между
  наблюдениями и не доказывает доступность цены для ставки.

## Проверки

```bash
.venv/bin/python -m unittest discover -v
python3 tests/browser_capture_smoke.py
```

Тесты включают реальные публичные DOM-примеры, отдельные рынки и таймы,
фильтрацию live/хоккея, MSK/UTC, повторный импорт, неизменяемость истории,
отсутствие утечки будущих результатов и транспортный контракт SSH. Браузерный
сбор проверяется на локальном HTTP-сайте; реальное получение из исходного
пользовательского файла подтверждено отдельно. Долговременная работа на VPS
или непрерывность внешних сайтов этими тестами не подтверждается.
