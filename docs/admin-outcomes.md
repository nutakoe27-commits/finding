# Результаты и токены ИИ в админке

В `#admin` добавлены вкладки **«Результаты ИИ»** и **«Токены ИИ»**.
Обе используют API с проверкой роли администратора. При выходе из аккаунта
данные очищаются. Обновление выполняется раз в минуту только в открытой вкладке.

## Результаты

Сохранённые предматчевые ответы Qwen сверяются с текущим архивом Winline без
новой генерации. В периоде учитывается первый допустимый разбор каждого матча;
можно выбрать конкретную версию. Повторы, live, ответы после начала и технические
пропуски не повышают точность. Даты и графики относятся к началу матча по МСК.
Неоднозначные результаты, дополнительное время и пенальти не выдаются за исход
основного времени. При обновлении итогов архива показатели пересчитываются.

«Отчёт пересчитан» — время проверки сохранённых данных, а не время доставки
результатов. Отдельный индикатор показывает последний приём архива и состояния:
нет связи со сборщиком, устаревшие данные источника, передача накопленных итогов
или нормальная доставка. Если доставка остановилась, у неподтверждённых матчей
указана эта причина; выигрыш или проигрыш не придумываются. После получения
итогов те же сохранённые прогнозы пересчитываются без генерации новых ответов.

Для проверки доставки на сервере сборщика:

```bash
sudo systemctl show winline-archive.service winline-archive-sync.service -p Id -p ActiveState -p SubState -p NRestarts --no-pager
sudo cat /var/lib/winline-archive/status.json /var/lib/winline-archive/sync-status.json
sudo journalctl -u winline-archive-sync.service -n 15 --no-pager -o cat
```

Эти проверки читают состояние архива и синхронизации; службы модели к ним
не относятся. Публичный `/api/archive/status` показывает состояние доставки
на стороне сайта. Пока новых итогов в архиве нет, пересчёт админки сам по себе
не может подтвердить завершённые встречи.


Попадание в победителя считается отдельно от решения о ставке. Для П1/П2 ничья
означает промах. При пропуске показываются «избежал проигрыша», «пропущена победа»
или «без предпочтения». Это описание по известному итогу, не доказательство
ошибочности или правильности решения в момент прогноза.

Виртуальный банк начинается со 100 единиц. Учитываются только рекомендации
ставить с сохранённой свежей ценой и корректной долей исходного банка. Пропуск
не создаёт виртуальную прибыль. Реальные деньги и платёжный баланс не меняются.

Источник «Архивные тесты» читает обычные файлы `neural-verdict*.json` из
`data/evaluations` в каталоге приложения. Он отделён от реальных разборов сайта.
Проверяется хеш входа; счёт и прибыль из JSON не используются вместо архива.
Произвольные пути, симлинки и файлы больше 8 МиБ не принимаются.

## Токены

Записывается фактический `usage` Chat Completions: вход, выход, сумма,
максимальный вход одного вызова и пик с запрошенным резервом ответа.
Расход запроса включает отклонённые ответы и исправления; пик окна не равен
сумме токенов всех повторов. Учёт изолирован между запросами и фоновой очередью.
Кэш не повторяет расход исходной генерации.

Таймаут без `usage` остаётся неизвестным расходом. Частичные суммы помечаются
знаком ≥. Старые записи не оцениваются по байтам и не входят в перцентили.
Это токены модели, а не продаваемые пользователю единицы внутреннего баланса.

API: `/api/admin/verdict-outcomes` и `/api/admin/ai-token-usage`.
Доступны периоды 7/30/90 дней, фильтры и постраничная детализация.
Сырой промпт и пользовательские заметки в эти отчёты не передаются.

## Обновление

```bash
cd /root/matchlab &&
git pull --ff-only origin main &&
sudo systemctl restart matchlab.service
```

Новых служб и миграций не требуется. Сборщики и сервер модели продолжают работать.
